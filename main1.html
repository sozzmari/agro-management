🌱 Agro-Monitoring System

Task 1.1: Classification of Requirements

🔐

1. User Authentication

The user must be able to log into the system using a username and password.

📊

2. Sensor Data Display

The system must display temperature and humidity data collected from field sensors.

👥

3. User Management

The administrator must be able to add new users to the system.

📑

4. Reports Generation

The system must be able to generate and download reports for a selected period.

⚡

1. Performance

The response time for all API requests must not exceed 2 seconds.

🛡️

2. Security

Passwords in the database must be stored in a hashed (encrypted) format.

📱

3. Usability

The interface must be responsive, adapting to both mobile and desktop screens.

⏱️

4. Availability

The system must maintain an uptime of 99.5%.
